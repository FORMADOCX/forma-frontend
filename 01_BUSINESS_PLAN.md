# FORMA — бізнес-план (working draft)

**Версія:** 1.0 · **Дата:** 2026-11-18 · **Статус:** стратегічний план, не фінансовий прогноз із підтвердженим попитом.  
**Бренд і домен:** робочі; фінальний вибір відкладено.

## 1. Executive summary

FORMA — англомовна за замовчуванням, мультимовна бібліотека редагованих шаблонів документів (DOCX, XLSX, PDF та інші дозволені формати) з якісними справжніми прев’ю, категоріями, пошуком і SEO-сторінками для кожного шаблону. Контент розширюється командою і незалежними авторами; публікація користувацьких матеріалів тільки після модерації. Українська — друга локаль з першого релізу. Модель запуску: безкоштовний каталог, органічний пошук + внески авторів. Монетизація — після перевірки traction, не обов’язкова в MVP.

### Продуктова обіцянка
«Find a useful document. See exactly what you get. Download and edit it.» Відрізняємося не кількістю генеративного контенту, а придатністю шаблонів для реальної роботи, послідовним дизайном, точним прев’ю, хорошим пошуком і перевіркою якості.

## 2. Сегменти й Jobs to Be Done

| Сегмент | Потреба | Приклади пошуку |
|---|---|---|
| Фрилансери, соло-спеціалісти | Швидко виставити рахунок або надіслати пропозицію | clean invoice template, project proposal docx |
| Малі бізнеси, агенції | Базові робочі документи без дизайнера | meeting notes template, creative brief |
| Шукачі роботи | Оформити резюме | minimal CV template |
| Студенти й організатори | Планування, бюджети, нотатки | budget spreadsheet, planner template |
| Дизайнери та автори | Публікація робіт і вихід на аудиторію | submit template, showcase portfolio |

Початковий фокус (гіпотеза): freelance / small business productivity. Не намагатися одночасно ранжуватися за всіма типами документів.

## 3. Продукт і інформаційна архітектура

- Home: короткий вступ, пошук, обрані категорії, нові/популярні роботи, посилання на каталог.
- All Templates: серверно індексована колекція, фільтри (категорія, формат, тип/призначення, стиль), сортування, пагінація.
- Category: власна SEO-посадкова зі вступом, вкладеними категоріями, списком шаблонів, поясненням і внутрішніми посиланнями.
- Template Detail: власний URL, прев’ю реального файлу, опис, специфікація, інструкція, автор, атрибути, доступні формати, пов’язані шаблони, download.
- Quick Preview: невелике вікно без великого SEO-тексту; назва, одне велике прев’ю, 1–2 речення, формат, кнопки View details / Download.
- Submit: завантаження файлу, метаданих, авторського портфоліо, згода з правилами; статус pending до редакторського рішення.
- Static pages: About, Contact, Submit Guidelines, Terms, Privacy, Copyright / Takedown.

## 4. Бізнес-модель

### Етап 1: перевірка потреби (MVP)
- Безкоштовні завантаження, без paywall; SEO + вимірювання реальної цінності контенту.
- Унікальний авторський контент із права́ми на розповсюдження, не масова генерація майже однакових файлів.
- Винагорода автору на першому етапі — атрибуція та перевірені посилання на портфоліо; без обіцянки трафіку.

### Етап 2: можливості монетизації (після traction)
1. Платні тематичні набори або premium templates.
2. Продаж ліцензій для команд або комерційного використання, якщо оформлено права.
3. Обмежене спонсорство/партнерські інтеграції з позначенням реклами.
4. Пізніше — інструмент створення/заповнення шаблонів онлайн.

Не додавати платежі та профілі авторів у перший реліз без доказів попиту.

## 5. Go-to-market і SEO

### Стартова контентна структура
- 6 наявних шаблонів як seed (Invoice, Project Proposal, CV, Creative Brief, Budget Tracker, Meeting Notes), далі 20–30 **справді різних** корисних документів.
- Перші 3–5 категорій із семантичними кластерами: Business, Finance, Career, Planning, Creative.
- Кожна сторінка шаблону має відповідати власній задачі та пошуковому наміру; не робити дублікати лише під варіації ключових слів.
- EN основна мова. UK — повноцінний переклад UI, редакційних сторінок і SEO-полів для сторінок, що публікуються українською. Переклад назви файлу не означає локалізацію самого документу.

### Канали
- SEO: категорії, template details, тематичні добірки лише за наявності редакторської цінності.
- Автори: портфоліо-атрибуція, посилання авторів на їхні публікації.
- Релевантні спільноти й добірки; без спаму.
- Email-розсилка і соцмережі — тільки після стійкого виробництва контенту.

### SEO-політика
- SSR/SSG, постійні URL; окрема meta-модель для locale.
- Canonical, hreflang, XML sitemaps, robots, 404/410/301, Open Graph, правильні заголовки.
- Керувати індексацією фасетних URL: звичайні комбінації фільтрів не повинні створювати тисячі дубльованих індексованих сторінок.
- JSON-LD тільки для фактично відповідних типів і реальних даних. Ніяких гарантій rich snippets або позицій.
- Актуальні рекомендації: [Google localized versions](https://developers.google.com/search/docs/specialty/international/localized-versions), [Google faceted navigation](https://developers.google.com/crawling/docs/faceted-navigation).

## 6. Воронка та метрики

| Етап | Подія / KPI | Що вважати успіхом |
|---|---|---|
| Search visibility | Impressions, indexed pages, non-brand clicks | зростання релевантних показів, відсутність технічних блокерів |
| Discovery | search_submitted, filter_applied, template_opened | користувачі знаходять релевантні сторінки |
| Engagement | quick_preview_opened, detail_viewed | зрозуміле рішення про завантаження |
| Value | download_started, download_completed* | частка відвідувачів, які завантажують файли |
| Supply | submission_started, submission_sent | надходять якісні матеріали |
| Quality | approval_rate, avg_review_time, reports | якісна редакторська робота |

\* «Completed» на стороні браузера не завжди можна достовірно визначити; відстежувати успішно виданий download URL / серверну відповідь.

**Пілотні цілі для обговорення, НЕ прогнози:** 20–30 перевірених шаблонів на запуск; 0 несанкціонованих публікацій; 100% опублікованих файлів із реальним прев’ю; 100% ключових сторінок із перевіреними title/canonical; перші 90 днів виміряти кількість завантажень і частку користувачів, які повертаються.

## 7. Орієнтовна економіка (ілюстративні сценарії)

Цифри нижче — **припущення**, а не ринкові ставки. Уточнюються після вибору стека, хостингу й обсягу трафіку.

| Стаття | Lean MVP / місяць | Growth / місяць |
|---|---:|---:|
| Hosting + database | $0–50 | $50–250 |
| Object storage + traffic | $0–30 | $30–200+ |
| Email, monitoring, search | $0–40 | $40–200 |
| Domain (усереднений річний) | $1–3 | $1–3 |
| **Разом інфраструктура** | **$1–123** | **$121–653+** |

Не включено: розробка, дизайн, редактор, створення й QA шаблонів, юридичні послуги, маркетинг, податки, платні API, непередбачуваний egress. Значне використання preview rendering/AV scanning може вимагати окремих витрат.

**Окремо оцінювати роботу:** frontend, backend/CMS, SEO, file pipeline, QA, security. Вартість залежить від виконавців; надійно назвати її без оцінки задач не можна.

## 8. Ризики та контролі

| Ризик | Протидія |
|---|---|
| Шкідливі завантажені файли | обмежені формати, перевірка вмісту, antivirus/sandbox, quarantine, приватний storage |
| Порушення авторських прав | правила подання, декларація прав, можливість скарги та takedown |
| Thin/duplicate SEO pages | редакторські пороги якості, керована індексація, канонікали |
| Неефективний пошук | окремий індекс із locale-aware полями, вимірювання нульових результатів |
| Занадто багато ручної модерації | чеклісти, черга, автоматичні технічні перевірки |
| Неузгоджені локалізації | per-locale статус, fallback для UI, без хибних hreflang для відсутніх перекладів |
| CDN leak / hotlinks | оригінали приватні, короткоживучі підписані URL; відкриті прев’ю без секретів |

## 9. Roadmap із критеріями виходу

1. **Foundation:** контентна модель, auth, roles, storage, rendering pipeline, CMS, localized routes. Вихід: у staging створюються й публікуються шаблони тільки адміном.
2. **Marketplace-lite:** public submission, queue, moderation, rejection feedback, author attribution. Вихід: жодна pending submission не доступна публічно.
3. **SEO release:** 20–30 шаблонів, quality checks, sitemaps, Search Console, analytics. Вихід: сканування сторінок без критичних помилок.
4. **Optimization:** контентні кластери, пошук, релевантність, оптимізація швидкості. Вихід: рішення за фактичними метриками.
5. **Monetization (optional):** після доказів попиту.

## 10. Невирішені продуктні питання

- Фінальна назва, домен і колір (пропозиція: приглушений зелений або кобальтовий, лише один).
- Які саме file types приймати: рекомендовано DOCX, XLSX, PDF; інші — після перевірки безпеки.
- Чи потрібна безкоштовна авторизація користувача для надсилання: рекомендовано не вимагати логін для перегляду, але вимагати email verification для подання.
- Точна ліцензія шаблонів, повторне використання, чи дозволено продаж.
- Чи можна зберігати портфоліо-посилання на будь-які домени; потрібна політика external links.
- Чи будуть завантаження безкоштовними назавжди.
- Бюджет, строки, команда, юридична юрисдикція.
